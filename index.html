Introduction I was the sole developer of a game that made me around $10k and had been played around 5 million different times by the time it died off a few years after release. Throughout that time period, I learned a lot about security and why it matters so much and became fascinated with information security. Since then, I have applied concepts of information security I’ve learned into some of my projects. The most useful project I’ve completed so far was setting up a server that runs an open source and fully local version of Google Home called Home Assistant on a Raspberry Pi. I used it to set up my own encrypted DNS server that could also block known tracking or advertising domains from being visible on all devices across my network. Not long after, I set up a Cloudflare tunnel to expose my home assistant instance to the internet by running it through a domain I purchased so I didn’t have to risk exposing my router by opening a port.
